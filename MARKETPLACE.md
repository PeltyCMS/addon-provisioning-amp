**Tagline:** Provision AMP services from PeltyCMS orders

## AMP provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on AMP when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable AMP API/panel
- API token or login configured in Pelty
